
======================================================================
AMP3 MODEL INPUT/OUTPUT STRUCTURE
======================================================================

ACTOR NETWORK INPUTS:
  1. personal        (batch, 8)   - Hole cards + stack/pot/bet info
  2. public          (batch, 22)  - Community cards + all stacks/bets
  3. position        (batch, 6)   - One-hot position (0-5)
  4. action_history  (seq, batch, 2) - Past actions sequence
  5. style_features  (batch, 24)  - Opponent style profiles (6 players × 4)

ACTOR NETWORK OUTPUT:
  • action_logits    (batch, 4)   - [FOLD, CALL, RAISE_SMALL, RAISE_LARGE]
  • action_probs     (batch, 4)   - Softmax probabilities
  • predicted_action (int)        - Argmax of logits

----------------------------------------------------------------------

CRITIC NETWORK INPUTS:
  1. all_holes       (batch, 24)  - All players' hole cards
  2. public          (batch, 22)  - Community cards + stacks/bets
  3. position        (batch, 6)   - One-hot position
  4. action_history  (seq, batch, 2) - Past actions sequence

CRITIC NETWORK OUTPUT:
  • value            (batch, 1)   - Estimated state value
